Leonida Platinum — the best offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a guide in our own words that cites its sources, a five-stage roadmap to the platinum, the 7 missable trophies flagged with their closing windows, and a checklist saved in the browser with export/import, filters by kind, and a spoiler setting that hides story trophies until earned. Works with the network off.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or open app/index.html from any static file server with app/ at its root.
